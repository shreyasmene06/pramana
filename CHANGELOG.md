# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-11-26

### Added
- **Core Math Engines:** 90+ algorithmic math and puzzle generation engines spanning arithmetic, algebra, geometry, calculus, statistics, number theory, and logic.
- **Adaptive Difficulty:** 4-tier real-time difficulty adaptation responding to learner speed and accuracy.
- **Interactive Labs:** Visual manipulatives, spatial geometry canvases, and step-by-step interactive solvers.
- **Multiplayer Arena:** Real-time 1v1 battle arena using WebSockets.
- **Detective Agency:** Story-driven deduction mysteries and logic cases.
- **Error Recovery:** Misconception classification and targeted guided recovery exercises.
- **Client Application:** React 19 + Vite frontend with dark/light themes and responsive mobile support.
- **Backend API:** Node.js Express server with MongoDB persistence and standalone evaluation endpoints.
